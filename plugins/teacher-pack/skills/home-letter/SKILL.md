# 가정통신문

> 이 스킬의 목적 하나: **빈 화면을 없애는 것.**
> 교사는 통신문을 못 쓰는 게 아니라 시작을 못 한다. 고치는 건 5분이면 된다.

## 0. 절대 규칙 세 가지

**하나. 학생 실명을 쓰지 않는다.**
입력에 실명이 있으면 그대로 두지 말고 `○○○` 로 바꾼 뒤 한 줄로 알린다.
> 실명은 `○○○` 로 바꿨습니다. 통신문은 전체 배부물이라 개별 학생 이름이 들어가면 안 됩니다.

**둘. 모르는 정보를 지어내지 않는다.**
날짜·시각·금액·장소·연락처가 주어지지 않았으면 **반드시 대괄호로 비워 둔다.**

```
일시: [ 월 일 (요일) ] 오전 [ 시 ]
비용: [ 원 ] (예산 확정 후 안내)
장소: [ 장소명 ]
```

그럴듯한 값을 채우면 교사가 못 보고 그대로 발송한다. **비워 두는 것이 안전하다.**

**셋. 학교명·교장 명의는 주어졌을 때만 쓴다.** 없으면 `[ ○○초등학교장 ]`.

## 1. 먼저 확인할 것 — 세 개만

이미 알 수 있으면 묻지 않는다. 모르면 이 세 개만 묻고 바로 쓴다.

| 물을 것 | 왜 |
|---|---|
| **무슨 일인지** | 행사·안내·수합·협조 중 무엇이냐에 따라 구조가 다르다 |
| **회신이 필요한가** | 필요하면 절취선과 회신란이 붙는다 |
| **학년·반** | 발신 명의와 문체가 달라진다 |

나머지(분량·톤·표 사용)는 **묻지 말고 아래 기본값으로 간다.**

## 2. 기본 형식

```
                    가정통신문
                                        [ ○○초등학교 ]

제목: (한 줄, 명사형)

  학부모님께 드리는 인사 (2~3문장)
  — 계절 인사 한 문장 + 협조에 대한 감사 한 문장

  ■ 안내 내용
  (본문 3~6문장. 왜 하는지 → 무엇을 하는지 → 학부모가 할 일)

  ■ 세부 사항
  (표)

  ■ 협조 사항
  (있으면 2~3개 항목)

  마무리 인사 (1~2문장)

                          [ 2026년 ○월 ○일 ]

                     [ ○○초등학교장 ]
```

### 표로 넣을 것

일시·장소·준비물·비용·복장은 **문장으로 늘어놓지 말고 표로 만든다.**
학부모는 통신문을 정독하지 않는다. 표만 본다.

| 구분 | 내용 |
|---|---|
| 일시 | |
| 장소 | |
| 준비물 | |
| 복장 | |
| 비용 | |

### 회신란 (필요할 때만)

```
- - - - - - - - - - - - - ✂ - - - - - - - - - - - - -

                    회  신  서

           ○학년 ○반  학생명 __________

  ㅁ 참가함     ㅁ 참가하지 않음

  학부모 성명 __________ (서명)

                        [ 회신 마감일 ]까지 제출
```

## 3. 문체

- **정중하되 딱딱하지 않게.** 공문 말투를 그대로 쓰면 안 읽힌다.
- `~하시기 바랍니다` 는 꼭 필요한 곳에만. 나머지는 `~해 주시면 감사하겠습니다`.
- 한 문장 **40자 이내**. 길면 자른다.
- 전문용어를 풀어 쓴다. `학교교육과정 연계 체험활동` → `수업과 이어지는 현장체험학습`
- 명령형·통보형 금지. `제출할 것` → `제출해 주세요`

## 4. 쓰고 나서 반드시 점검 — 이게 이 스킬의 값이다

초안을 낸 뒤 **아래를 직접 확인하고 결과를 알린다.**

| 점검 | 어떻게 |
|---|---|
| **날짜와 요일이 맞는가** | 실제로 계산해 본다. "10월 15일(수)"가 맞는지. 틀리면 고치고 알린다 |
| **비워 둔 칸이 남았는가** | `[ ]` 가 몇 개 남았는지 세어서 알린다 |
| **회신 마감일이 행사일보다 앞서는가** | 뒤면 지적한다 |
| **학생 실명이 남았는가** | 있으면 바꾸고 알린다 |
| **분량** | A4 한 장을 넘으면 줄일 곳을 제안한다 |

점검 결과를 이렇게 한 줄로 낸다.

> 확인했습니다 — 채우실 칸 3개(`[ 금액 ]` `[ 회신 마감일 ]` `[ 학교명 ]`),
> 10월 15일은 목요일입니다(수요일로 적혀 있어 고쳤습니다).

## 5. 마지막에 반드시 제안한다

> 워드 파일로 만들어 드릴까요? 학교 양식에 붙여 쓰시기 편합니다.

한다고 하면 **.docx 로 만든다.** 제목은 `가정통신문_주제_날짜.docx`.

## 6. 하지 않는 것

- **완성본이라고 말하지 않는다.** 초안이다. 교사가 학교 양식과 사실을 확인해야 한다
- 학교 규정·법령 조항을 **인용하지 않는다.** 확인할 수 없다
- 안전·보건 관련 문구를 **임의로 만들지 않는다.** 학교 표준 문구가 따로 있다
- 비용을 **추정하지 않는다.** 반드시 비워 둔다

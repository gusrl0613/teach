# 학교 행정 문서

> 이 스킬의 목적 하나: **형식 때문에 못 시작하는 걸 없애는 것.**
> 계획서 내용은 교사 머릿속에 다 있다. 막히는 건 "이걸 어떤 칸에 넣지"다.

## 0. 절대 규칙 — 이 셋은 예외 없다

**하나. 근거 법령·지침·조항을 지어내지 않는다.**

`「학교보건법」 제9조에 따라` 같은 문장을 기억으로 쓰지 않는다.
**조문 번호가 틀린 채 결재가 올라가면 그게 그대로 남는다.**

```
1. 관련
   가. [ 근거 문서명·번호를 담당 부서에서 확인해 채워 주세요 ]
   나. 본교 [ 2026학년도 ○○ 계획 ]
```

교사가 근거 공문을 첨부하면 **그것만 인용**한다.

**둘. 예산 금액을 추정하지 않는다.**
단가·총액을 그럴듯하게 채우지 않는다. 항목만 세우고 금액은 `[ ]` 로 둔다.

**셋. 결재선·문서번호·시행일을 만들지 않는다.** 학교마다 다르고 시스템이 부여한다.

## 1. 문서 종류를 먼저 정한다

| 종류 | 언제 | 뼈대 |
|---|---|---|
| **계획서** | 하기 전 | 목적 → 방침 → 세부계획 → 예산 → 기대효과 |
| **결과보고서** | 하고 나서 | 개요 → 추진내용 → 결과 → 성과·개선점 → 증빙 |
| **기안문** | 결재 요청 | 관련 → 목적 → 내용 → 협조·조치사항 |
| **품의서** | 돈 쓸 때 | 목적 → 내역(표) → 예산과목 → 업체 → 요청사항 |

입력을 보고 판단하되 **판단한 결과를 알린다.**
> **계획서**로 보고 썼습니다. 결과보고서가 필요하시면 말씀해 주세요.

## 2. 형식

```
1. 관련: [ 근거 ]

2. 목적
   가. (한 문장. "무엇을 위해")
   나.

3. 방침
   가. (운영 원칙 2~4개)

4. 세부 계획
   가. 기간: [ ]
   나. 대상: ○학년 학생 [ ]명
   다. 장소: [ ]
   라. 내용

   | 구분 | 내용 | 담당 | 비고 |
   |---|---|---|---|

5. 소요 예산
   | 항목 | 산출 내역 | 금액 |
   |---|---|---|
   | | [ 단가 × 수량 ] | [ ] |
   |  계 |  | [ ] |
   ※ 예산과목: [ ]

6. 기대 효과
   가.

붙임  1. [ ] 1부.  끝.
```

## 3. 행정 문서 문체

- **개조식.** 문장이 아니라 항목으로 끊는다
- 항목 번호는 `1. → 가. → 1) → 가)` 순서
- 서술어는 `~함`, `~하고자 함`, `~ 요청`
- **한 항목 한 줄.** 두 줄 넘으면 쪼갠다
- 감정·수식어를 넣지 않는다 (`매우 유익한`, `뜻깊은`)

### 목적은 한 문장으로

> ❌ 학생들의 창의성과 인성을 함양하고 협동심을 기르며 즐거운 학교생활을 통해...
> ✅ 학년 단위 협동 활동으로 교우 관계 형성을 지원하고자 함

## 4. 만들고 나서 점검

| 점검 | |
|---|---|
| **비워 둔 칸** | `[ ]` 개수를 세어 목록으로 알린다 |
| **날짜와 요일** | 계산해서 확인한다 |
| **예산 합계** | 금액이 채워져 있으면 실제로 더해 검산한다 |
| **항목 번호** | 순서가 어긋나지 않았는지 |
| **분량** | 계획서는 A4 1~2장. 넘으면 줄일 곳 제안 |

> 확인했습니다 — 채우실 칸 **7개**:
> 근거 공문 · 기간 · 장소 · 대상 인원 · 단가 3건 · 예산과목.
> 10월 15일은 목요일입니다.

## 5. 마지막에

> 워드로 뽑아 드릴까요? 학교 기안 양식에 붙여 넣으시면 됩니다.

`.docx` 로 만든다.

## 6. 하지 않는 것

- **법령·지침을 인용하지 않는다** (받은 문서가 있을 때만)
- 다른 학교 사례를 **사실인 것처럼 쓰지 않는다**
- 학생 실명·개인정보를 넣지 않는다. 인원과 학년까지만
- **"이대로 올리시면 됩니다"라고 하지 않는다.** 학교 양식과 결재선은 교사가 맞춰야 한다

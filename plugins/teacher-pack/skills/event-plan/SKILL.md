# 행사 기획

> 이 스킬의 목적 하나: **당일에 빠뜨리는 것을 미리 찾아내는 것.**
> 행사는 아이디어가 아니라 **동선과 시간**에서 무너진다.

## 0. 절대 규칙

**하나. 안전을 빠뜨리지 않는다.**
이동·물·불·높은 곳·도구·음식이 들어가면 **⚠️ 로 표시하고 유의사항을 붙인다.**
다만 **학교 안전 규정을 지어내지 않는다.** 학교 표준 지침이 따로 있다고 안내한다.

**둘. 비용을 추정하지 않는다.** 항목만 세우고 금액은 `[ ]` 로 둔다.

**셋. 인원과 시간을 실제로 계산한다.**
`한 명씩 발표 — 5분` 은 24명이면 **2시간**이다. 계산해서 알린다.

## 1. 출력 형태

```
■ 개요
   일시 / 장소 / 대상 / 목적 한 줄

■ 진행표
   | 시각 | 내용 | 장소 | 담당 | 준비물 |
   |---|---|---|---|---|
                                    합계 ○○분

■ 역할
   | 누가 | 무엇을 | 언제부터 |

■ 준비 일정 (D-day 역산)
   | 언제 | 할 일 | 담당 |

■ ⚠️ 안전
   · (해당되는 것만)

■ 이렇게 되면
   · 비가 오면 →
   · 시간이 밀리면 → (무엇부터 줄일지)
   · 아이가 다치면 → (누가 어디로)
```

## 2. "이렇게 되면" 이 이 스킬의 값이다

계획대로 되는 행사는 없다. **밀렸을 때 무엇을 버릴지 미리 정해두면** 당일에 당황하지 않는다.

> 시간이 밀리면 버리는 순서: ① 중간 놀이 ② 사진 촬영 ③ 소감 나누기
> **절대 못 버리는 것: 안전 안내 · 귀가 시간**

## 3. 준비 일정은 거꾸로

행사일에서 역산한다. 무엇이 **언제까지** 되어 있어야 하는지가 보인다.

| 언제 | 할 일 |
|---|---|
| D-14 | 장소 예약, 통신문 초안 |
| D-10 | 통신문 발송 (회신 기간 확보) |
| D-3 | 회신 집계, 준비물 구입 |
| D-1 | 물품 배치, 동선 확인 |

**통신문은 D-10 안팎**에 나가야 회신 받을 시간이 남는다. 이걸 자주 놓친다.

## 4. 점검하고 알린다

| 점검 | |
|---|---|
| **시간 합계** | 실제로 더한다. 예정 시간을 넘으면 줄일 곳 제안 |
| **한 사람이 동시에 두 곳** | 역할표에서 겹치는지 확인 |
| **이동 시간** | 장소가 바뀌면 최소 5분을 넣는다 |
| **날짜·요일** | 계산해서 확인 |
| **비는 시간** | 아이들이 기다리기만 하는 구간이 있는지 |

## 5. 하지 않는 것

- **학교 안전 규정·매뉴얼을 인용하지 않는다**
- 외부 업체·장소를 **확인 없이 추천하지 않는다**
- 비용을 **추정하지 않는다**
- 학부모 동원을 **당연한 것으로 넣지 않는다**
- 아이 개인의 역할을 **실명으로 배정하지 않는다.** 번호나 모둠으로

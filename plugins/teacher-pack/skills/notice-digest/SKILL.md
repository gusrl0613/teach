# 공문 · 안내 간추리기

> 이 스킬의 목적 하나: **기한을 놓치지 않는 것.**
> 공문은 길고, 우리 학년이 할 일은 대개 두세 줄이다. 그 두세 줄을 찾는 데 시간이 든다.

## 0. 절대 규칙

**하나. 원문에 없는 것을 만들지 않는다.**
기한·담당·제출처가 안 적혀 있으면 **비워 두고 표시한다.** 추측해서 채우면 그대로 움직이게 된다.

```
· 기한: [ 원문에 없음 — 확인 필요 ]
· 제출처: 교무실 (원문: "교무부로 제출")
```

**둘. 원문 표현을 왜곡하지 않는다.**
`권장한다` 를 `해야 한다` 로 바꾸지 않는다. 강도가 달라지면 판단이 달라진다.

| 원문 | 이렇게 적는다 |
|---|---|
| ~할 수 있음 | **선택** |
| ~하기 바람 | **권장** |
| ~할 것 / ~하여 주시기 바랍니다 | **필수** |

**셋. 법령·조항을 인용하지 않는다.** 원문에 있는 것만 그대로 옮긴다.

## 1. 출력 형태

```
■ 한 줄 요약
   (무엇을 언제까지)

■ 우리 학년이 할 일
   | 할 일 | 누가 | 언제까지 | 강도 |
   |---|---|---|---|

■ 아이들에게 안내할 것
   (있으면. 알림장·통신문 중 어느 쪽인지도)

■ 확인이 필요한 것
   · (원문에서 애매한 부분)

■ 안 해도 되는 것
   (공문에 있지만 우리 학년과 무관한 부분 — 이것도 알려주면 안심이 된다)
```

**"안 해도 되는 것"을 꼭 넣는다.** 공문이 길면 교사는 다 해야 하나 싶어 불안하다.

## 2. 기한 계산

날짜가 나오면 **오늘로부터 며칠 남았는지** 계산해 붙인다.

> · 9월 12일(금)까지 — **8일 남음**
> · 9월 5일(토)까지 — ⚠️ **내일입니다**

기한이 **주말·공휴일**이면 알린다. 실제로 낼 수 있는 날이 하루 앞당겨진다.

## 3. 동학년 전달용

`동학년에 보낼 메시지도 만들어 드릴까요?` 를 제안한다.
메신저에 그대로 붙일 수 있게 **5줄 이내**로.

```
[9/12까지] 안전교육 실적 입력
· 각 반 담임이 나이스에 직접 입력
· 2차시 이상, 사진 1장 첨부
· 자세한 건 원문 보세요
```

## 4. 하지 않는 것

- **원문을 대신 읽었다고 하지 않는다.** 중요한 공문은 교사가 직접 봐야 한다.
  요약 끝에 이렇게 적는다 — *"판단이 필요한 부분은 원문을 확인하세요."*
- 학교 내부 절차를 **추측하지 않는다** (결재선·제출 방법은 학교마다 다르다)
- 여러 공문을 **한꺼번에 섞지 않는다.** 하나씩 처리한다
- 개인정보가 든 명단이 첨부돼 있으면 **그 부분은 빼고** 작업하라고 안내한다

# 학급 세우기

> 이 스킬의 목적 하나: **규칙을 대신 정해주지 않는 것.**
> 교사가 만들어 붙인 규칙은 벽에만 남는다. 아이들이 정한 규칙만 지켜진다.

## 0. 절대 규칙

**하나. 학급 규칙을 완성해서 주지 않는다.**
교사가 "규칙 만들어줘" 라고 해도 **규칙 목록 대신 정하는 절차**를 준다.

> 규칙을 제가 만들어 드리면 아이들에게는 남의 규칙이 됩니다.
> **아이들과 함께 정하는 절차**를 만들어 드리겠습니다. 예시 문장도 함께 드릴 테니
> 아이들 이야기가 막힐 때 꺼내 쓰세요.

**둘. 벌 규정을 만들지 않는다.**
`어기면 ○○` 형태를 제안하지 않는다. 초등에서 벌 규정은 대개 역효과가 크고,
학교 생활규정과 충돌할 수 있다. 대신 **어겼을 때 어떻게 할지 아이들과 이야기하는 질문**을 준다.

**셋. 학생 실명을 쓰지 않는다.** 1인 1역 배정은 **번호**로.

## 1. 학급 규칙 — 절차를 준다

```
1차시  왜 규칙이 필요한가
       "규칙이 하나도 없는 교실을 상상해 보자"
2차시  어떤 교실이면 좋겠는지
       모둠별로 3개씩 → 비슷한 것끼리 묶기
3차시  문장으로 다듬기
       금지문("~하지 않기")을 행동문("~하기")으로 바꾸기
4차시  약속하고 붙이기
```

### 문장 다듬기 원칙

| 이렇게 나오면 | 이렇게 바꾼다 |
|---|---|
| 떠들지 않기 | 다른 사람이 말할 때 듣기 |
| 때리지 않기 | 몸에 손대지 않기 |
| 지각하지 않기 | 9시까지 자리에 앉기 |

**금지문은 무엇을 하면 되는지 알려주지 않는다.** 행동문으로 바꾸면 아이가 할 일이 보인다.
규칙은 **5개 안팎.** 많으면 아무도 못 외운다.

## 2. 1인 1역

24명이면 24개 역할이 필요하다. 억지로 만들지 말고 **겹치게** 둔다.

| 역할 | 인원 | 하는 일 | 언제 |
|---|---|---|---|
| 칠판 | 2 | 쉬는 시간마다 지우기 | 매 교시 후 |
| 창문 | 2 | 아침 열기, 하교 전 닫기 | 아침·하교 |
| ... | | | |

- **일이 없는 역할을 만들지 않는다.** 할 게 없으면 아이도 안 한다
- **언제 하는지**를 반드시 적는다. 이게 없으면 아무도 안 한다
- 배정은 **번호로.** 교사가 아이 이름을 넣는다
- 바꾸는 주기(2주·한 달)를 함께 제안한다

## 3. 첫 주 일정

```
1일차  이름 익히기 · 자리 · 화장실/급식 동선 · 안전
2일차  시간표 · 준비물 · 알림장 쓰는 법
3일차  학급 규칙 시작 (1~2차시)
4일차  1인 1역 정하기
5일차  규칙 다듬고 붙이기 · 첫 주 돌아보기
```

**동선과 안전을 1일차에 둔다.** 화장실·급식실·비상구를 모르면 아이가 불안하다.

## 4. 학부모 첫 안내

`학부모께 보낼 첫 통신문도 만들어 드릴까요?` 를 제안한다.
담임 소개 · 연락 방법과 시간 · 학급 운영 방향 · 준비물.
자세한 형식은 `home-letter` 로 넘긴다.

## 5. 하지 않는 것

- **규칙 목록을 완성해서 주지 않는다** (예시 문장까지만)
- **벌·상점 제도를 설계하지 않는다**
- 학교 생활규정을 **인용하지 않는다**
- 아이 성향을 **미리 단정하지 않는다** (`활발한 아이에게는 ○○ 역할`)

# 읽기 자료 수준 조정

> 이 스킬의 목적 하나: **쉽게 만들되 내용을 바꾸지 않는 것.**
> 어휘를 낮추다가 주장이 달라지면 그건 다른 글이다.

## 0. 절대 규칙

**하나. 사실과 주장을 바꾸지 않는다.**
어려운 낱말을 쉬운 낱말로, 긴 문장을 짧은 문장으로. **거기까지다.**

| 바꿔도 되는 것 | 바꾸면 안 되는 것 |
|---|---|
| 어휘 · 문장 길이 · 문단 나눔 | 숫자 · 인용 · 인과관계 |
| 어순 · 접속 표현 | 글쓴이의 주장과 강도 |
| 예시를 아이에게 익숙한 것으로 | **없던 예시를 지어내는 것** |

**둘. 애매하면 줄인다.** 쉽게 못 쓰겠는 문장은 **잘라낸다.** 억지로 바꾸다 뜻이 어긋나는 것보다 낫다.
잘라낸 것은 **잘라냈다고 알린다.**

**셋. 원문을 그대로 두라고 한다.** 출처와 원문 링크를 함께 남기라고 안내한다.
수업에 쓸 때 **어디서 온 글인지 아이도 알아야** 한다.

## 1. 학년 기준

| 학년 | 한 문장 | 한 문단 | 어휘 |
|---|---|---|---|
| 1~2 | 15자 안팎 | 2~3문장 | 일상어. 한자어 최소 |
| 3~4 | 25자 안팎 | 3~4문장 | 교과서에 나오는 한자어까지 |
| 5~6 | 40자 안팎 | 4~5문장 | 추상어 일부 허용, 처음 나오면 풀이 |

## 2. 함께 내는 것

### 바꾼 낱말 표

교사가 **무엇이 사라졌는지** 알아야 수업에서 짚어줄 수 있다.

| 원문 | 바꿈 | 비고 |
|---|---|---|
| 감소하였다 | 줄었다 | |
| 지속가능한 | 오래 이어갈 수 있는 | 5~6학년이면 원말도 함께 알려줄 만함 |
| 상충한다 | — | **문장째 잘라냄**. 이 학년엔 어렵습니다 |

### 수준별로 여러 벌

`3학년용과 5학년용 둘 다 만들어 드릴까요?` 를 제안한다.
같은 글을 두 수준으로 두면 **한 교실에서 나눠 줄 수 있다.**

## 3. 점검

| 점검 | |
|---|---|
| **숫자·고유명사** | 원문과 하나씩 대조한다. 틀리면 자료 전체가 못 쓴다 |
| **문장 길이** | 가장 긴 문장이 기준을 넘는지 센다 |
| **잘라낸 것** | 몇 문장을 뺐는지 알린다 |
| **분량 변화** | 원문 대비 몇 % 인지 |

## 4. 하지 않는 것

- **저작권 있는 글을 통째로 다시 써서 배포하라고 권하지 않는다.**
  수업 자료로 쓸 때의 범위는 학교 방침을 따르라고 안내한다
- 원문에 없는 **결론이나 교훈을 붙이지 않는다**
- 논쟁적 주제에서 **한쪽으로 기울이지 않는다**
- 글쓴이의 **감정 표현을 중화하지 않는다** (`끔찍했다` → `안 좋았다` 는 왜곡이다)

# 회의 · 협의회 정리

> 이 스킬의 목적 하나: **결정된 것과 안 된 것을 가르는 것.**
> 회의록이 쓸모없어지는 건 "이야기했다"와 "정했다"가 섞여 있을 때다.

## 0. 절대 규칙

**하나. 결정 / 미결 / 참고를 반드시 나눈다.**

| 구분 | 무엇 |
|---|---|
| **결정** | 누가 언제까지 할지가 정해진 것 |
| **미결** | 이야기는 했으나 결론이 안 난 것 |
| **참고** | 공유만 된 것 |

결정처럼 보이지만 담당이나 기한이 없으면 **미결**로 넣는다.
> ⚠️ '체험학습 장소는 과학관으로' — **누가 예약할지 안 정해졌습니다.** 미결로 두었습니다.

**둘. 없는 결정을 만들지 않는다.** 흐지부지 끝난 안건을 매끄럽게 정리하지 않는다.
흐지부지 끝났다는 게 사실이면 그렇게 적는다.

**셋. 발언자 실명은 교사가 정한다.**
기본은 **직위나 익명**(`3반`, `학년부장`)으로 두고, 실명이 필요하면 물어본다.
회의록이 돌아다니면 발언이 그대로 남는다.

## 1. 출력 형태

```
■ 2026-09-04 5학년 협의회
   참석: (인원만 또는 반 번호)

■ 결정
   | 안건 | 결정 | 담당 | 기한 |

■ 미결 — 다음에 정해야 할 것
   | 안건 | 어디까지 이야기됐나 | 왜 안 정해졌나 |

■ 참고 · 공유

■ 다음 회의
   · 일시: / 정할 것:
```

## 2. 할 일에는 반드시 셋

**무엇 · 누가 · 언제까지.** 하나라도 비면 미결이다.

| 안 됨 | 됨 |
|---|---|
| 체험학습 준비하기 | 과학관 예약 — 3반 — 9/10까지 |
| 안내장 나가기 | 통신문 초안 작성 — 1반 — 9/8까지 |

## 3. 점검하고 알린다

| 점검 | |
|---|---|
| **담당 없는 할 일** | 개수를 세어 알린다 |
| **기한 없는 할 일** | 〃 |
| **날짜와 요일** | 계산해서 확인 |
| **지난 회의 미결** | 교사가 지난 기록을 주면, **아직 안 끝난 것**을 짚는다 |

> 정리했습니다 — 결정 4건, **미결 3건**.
> ⚠️ 담당이 없는 할 일이 **2건**입니다(안내장, 물품 신청). 정하고 넘어가시는 게 좋겠습니다.

## 4. 전달용 짧은 버전

`동학년 메신저에 보낼 것도 만들어 드릴까요?` 를 제안한다.
**내 반이 할 일만** 뽑아 3~5줄로.

## 5. 하지 않는 것

- **회의에서 안 나온 의견을 덧붙이지 않는다**
- 참석자의 **태도를 적지 않는다** (`반대 의견이 강했음` 같은 서술)
- 학생·학부모 실명이 나왔으면 **번호나 익명으로** 바꾸고 알린다
- 인사·평가·징계 관련 내용은 **정리 대상이 아니라고 알린다.** 기록 자체가 위험하다

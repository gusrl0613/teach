# 평가문항 · 채점기준표

> 이 스킬의 목적 하나: **채점기준표까지 같이 나오게 하는 것.**
> 문항은 어떻게든 만든다. 오래 걸리는 건 "이 답을 몇 점 줄 것인가"다.

## 0. 절대 규칙

**하나. 정답과 해설 없이 문항만 내지 않는다.**
정답을 안 쓰면 검증이 안 되고, 검증 안 된 문항은 교사가 다시 다 풀어봐야 한다.
**문항 · 정답 · 해설 · 배점은 한 묶음이다.**

**둘. 성취기준 코드를 지어내지 않는다.**
`[4수01-05]` 같은 코드를 기억으로 쓰지 않는다. 틀리면 그대로 결재까지 올라간다.
교사가 성취기준 문서를 첨부하면 **그것만 인용**하고, 없으면 이렇게 쓴다.

```
성취기준: [ 학교 자료에서 확인해 채워 주세요 ]
평가요소: 분모가 같은 분수의 덧셈을 계산할 수 있다   ← 이건 내용으로 쓸 수 있다
```

**셋. 학년 수준 어휘를 지킨다.**
3학년 문제에 `구하시오` `~에 해당하는 것은` 같은 표현을 쓰지 않는다.

| 학년 | 문두 |
|---|---|
| 1~2 | `~해 보세요`, `알맞은 것에 ○표 하세요` |
| 3~4 | `~을 구해 보세요`, `알맞은 것을 고르세요` |
| 5~6 | `~을 구하시오`, `까닭을 쓰시오` 가능 |

## 1. 먼저 확인할 것 — 네 개

**학년 / 과목·단원 / 문항 수 / 평가 유형**(형성·단원·수행). 이 넷만 묻고 바로 만든다.
난이도 비율은 묻지 말고 기본값으로 간다 — **하 3 : 중 5 : 상 2**.

## 2. 문항 구성

| 유형 | 언제 | 주의 |
|---|---|---|
| **선택형** | 개념 확인 | 답지 4개. **길이를 비슷하게.** 긴 것이 정답인 티가 난다 |
| **단답형** | 계산·용어 | 표기 흔들림을 정답에 다 적는다 (`4/6`, `2/3`, `6분의 4`) |
| **서술형** | 이유·과정 | **반드시 채점기준 3단계** |
| **수행** | 활동 | 관찰 가능한 행동으로 기준을 쓴다 |

### 함정을 만들지 않는다

초등 평가는 **아는지 보는 것**이지 못 잡아내는 게 목적이 아니다.

- 부정 발문(`~이 아닌 것은`)은 **꼭 필요할 때만**, 쓰면 **굵게** 표시
- 한 문항에 두 가지를 묻지 않는다
- 답지에 `모두 정답` `정답 없음` 넣지 않는다

## 3. 서술형 채점기준 — 3단계 고정

```
[상] 분모를 같게 만드는 과정과 계산이 모두 바르게 나타남
[중] 방법은 알고 있으나 계산 실수가 있음
[하] 분모를 같게 만드는 과정을 시도하지 못함
```

**"성실히 서술함" 같은 태도 표현을 기준에 넣지 않는다.**
채점자가 다르면 점수가 달라진다. **관찰 가능한 것**만 쓴다.

## 4. 만들고 나서 검산 — 반드시 한다

| 검산 | |
|---|---|
| **배점 합계** | 실제로 더해서 총점과 맞는지 확인한다. 어림하지 않는다 |
| **문항별 난이도 분포** | 하/중/상 개수를 세어 표시한다 |
| **정답 위치 분포** | 선택형 정답이 ③에 몰려 있으면 알린다 |
| **직접 풀어본다** | 계산 문항은 실제로 풀어 정답을 검증한다. 틀리면 고치고 알린다 |

> 검산했습니다 — 총 10문항 **100점**(합계 확인), 난이도 하3·중5·상2,
> 정답 분포 ①2 ②3 ③3 ④2. **4번 문항의 답이 원래 12였는데 15로 잘못 적혀 있어 고쳤습니다.**

## 5. 출력

| 번호 | 유형 | 문항 | 정답 | 배점 | 난이도 | 채점기준 |
|---|---|---|---|---|---|---|

**"학생용 시험지와 교사용 정답지를 따로 만들어 드릴까요?"** 를 제안한다.
- 학생용: 문항만 (`.docx`)
- 교사용: 정답·해설·채점기준 포함 (`.xlsx`)

## 6. 하지 않는 것

- **교과서 쪽수·삽화를 인용하지 않는다.** 판본마다 다르다
- 특정 학생을 문항에 등장시키지 않는다 (`민수는 사과를 3개...` 는 가상 이름으로만)
- 시사·논쟁적 소재를 초등 문항에 넣지 않는다
- **완성본이라고 하지 않는다.** 교사가 학급 수준에 맞춰 손봐야 한다

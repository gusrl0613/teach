# 초등교사용 클로드 스킬 20종 (claude.ai 웹)

> 매번 반복하는 잔소리를 **파일로 한 번만 적어두는 것**이 스킬입니다.
>
> 지금까지: "가정통신문 써줘. 아 존댓말로. A4 한 장. 준비물은 표로. 회신란도 넣고..."
> 스킬 설치 후: **"가정통신문 써줘"** → 나머지는 이미 파일에 적혀 있습니다.

## 설치 (2분)

1. **설정 → 기능(Features) → "코드 실행 및 파일 생성" 켜기** ← 꺼져 있으면 아무것도 안 됩니다
2. **Customize → Skills → `+` → 스킬 만들기 → 스킬 업로드**
3. zip 파일 선택. **한 번에 하나씩**

설치하면 **부르지 않아도 알아서 뜹니다.** "가정통신문 써줘" 라고만 하면 됩니다.

> 📌 서피스마다 따로입니다. claude.ai에 올린 스킬은 클로드 코드에 안 뜹니다.

## 왜 이렇게 만들었나

스무 개가 **서로 다른 위험 하나씩**을 막습니다. 그게 이 팩의 정체성입니다.
대표적인 다섯만 적습니다 — 나머지는 [안내 페이지](../../../teach/skills.html)의 카드에서 빨간 칸을 보세요.

**`record-phrase` 생기부 문구**  
지어내는 것. 근거가 부족하면 문구를 만들지 않고 “부족하다”고 말합니다. 짧게 쓰는 것은 정직한 선택지입니다.

**`conflict-talk` 갈등 중재**  
교사를 판사로 만드는 것. 잘잘못을 판정하지 않고, 학교폭력 해당 여부도 판단하지 않습니다. 다만 반복·다수·상해 정황이면 학교 절차를 확인하라고 알립니다.

**`writing-feedback` 글쓰기 피드백**  
아이 글을 대신 고쳐주는 것. 고친 문장을 돌려주면 아이는 자기 글이 부족했다는 것만 배웁니다. 맞춤법은 세 개까지만 — 빨간 줄이 많으면 내용을 안 봅니다.

**`class-setup` 학급 세우기**  
규칙을 완성해서 주는 것과 벌 규정을 만드는 것. 초등에서 벌 규정은 역효과가 크고 학교 생활규정과 충돌할 수 있습니다.

**`notice-digest` 공문 간추리기**  
기한을 놓치는 것. 날짜를 오늘로부터 며칠 남았는지 계산하고, 기한이 주말이면 알립니다. 원문에 없는 건 [ 확인 필요 ]로 비워 둡니다.


## 스무 개를 관통하는 세 문장

> **하나. 학생 실명은 넣지 않는다.** 번호로 바꾸면 결과는 같고 위험만 사라집니다.
>
> **둘. 모르는 것은 지어내지 않는다.** 날짜·금액·법령·성취기준·근거 없는 문구 — 전부 비워 둡니다.
>
> **셋. AI는 초안을 쓰고, 판단은 선생님이 한다.** 스무 개 모두 출력 끝에 이 말을 남깁니다.

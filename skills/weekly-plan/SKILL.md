# 주간학습안내

> 이 스킬의 목적 하나: **금요일 오후 한 시간을 돌려주는 것.**
> 주간학습안내는 어려운 게 아니라 칸이 많아서 오래 걸린다.

## 0. 절대 규칙

**진도를 지어내지 않는다.**
교사가 단원·차시를 주지 않았으면 **채우지 말고 비워 둔다.**

```
| 3 | 수학 | [ 단원·차시 ] | |
```

"3학년 2학기 수학이면 보통 나눗셈" 같은 추측은 하지 않는다.
교과서는 출판사와 개정 시기에 따라 순서가 다르다. **틀린 진도가 나가면 학부모가 먼저 안다.**

교육과정 자료·진도표를 첨부하면 **그것만 근거로** 채운다.

## 1. 먼저 확인할 것 — 세 개

| 물을 것 | 없으면 |
|---|---|
| **학년·반, 주차(날짜 범위)** | 이건 반드시 묻는다 |
| **시간표** | 한 번 주면 다음부터 "지난번 시간표로"라고 하면 된다 |
| **이번 주 진도** | 없으면 비워 두고 그 사실을 알린다 |

## 2. 기본 형식

```
        ○학년 ○반 주간학습안내         [ 2026. ○. ○ ~ ○. ○ ]

┌─────┬──────┬──────────────────┬──────────┐
│ 교시│ 과목 │   학습 내용      │  준비물  │
└─────┴──────┴──────────────────┴──────────┘
        (요일별로 반복)

■ 이번 주 알림
  · (2~4개)

■ 준비물 모아보기
  · 월: / 화: / 수: / 목: / 금:
```

**"준비물 모아보기"를 반드시 넣는다.** 학부모는 요일별 표를 훑지 않는다.
가방 쌀 때 보는 건 이 줄 하나다.

## 3. 학습 내용 쓰는 법

- **아이가 무엇을 하는지**로 쓴다. 단원명만 적으면 안내가 아니다
  - `2. 분수의 덧셈` → `분모가 같은 분수의 덧셈 방법 알아보기`
- 한 칸 **20자 이내**. 길면 표가 깨진다
- 전문용어를 풀어 쓴다. `성취기준 도달도 확인` → `배운 내용 확인하기`

## 4. 준비물 원칙

- **실제로 그날 필요한 것만.** 매일 쓰는 것(연필·지우개)은 안 적는다
- **돈이 드는 것은 미리.** 준비물이 최소 2~3일 전에 안내되게 배치하고,
  당일 안내면 지적한다
  > 목요일 요리 활동 재료를 목요일에 안내하면 늦습니다. 지난주 안내에 넣으셨나요?
- **집에 없을 만한 것**은 학교에서 준비하는지 확인하라고 표시한다

## 5. 만들고 나서 점검 — 이게 값이다

| 점검 | 어떻게 |
|---|---|
| **날짜와 요일** | 실제로 계산한다. `10월 15일(수)`가 맞는지 |
| **공휴일·행사** | 그 주에 공휴일이 있으면 알린다. 확인 못 하면 물어본다 |
| **교시 수** | 학년별 수업 시수와 표의 칸 수가 맞는지 |
| **준비물 중복** | 같은 준비물이 여러 날 걸쳐 있으면 한 번만 안내하도록 제안 |
| **빈칸** | `[ ]` 가 몇 개 남았는지 센다 |

> 확인했습니다 — 10월 3일은 **개천절(공휴일)** 입니다. 화요일 칸을 비웠습니다.
> 채우실 곳 4개, 준비물 안내가 하루 전인 항목 1개(목요일 색종이).

## 6. 마지막에 제안

> 워드로 뽑아 드릴까요? 표가 들어가 있어 인쇄용으로 바로 쓰실 수 있습니다.

`.docx` 로 만든다. 파일명 `주간학습안내_○학년○반_○월○주.docx`.

## 7. 하지 않는 것

- **교과서 쪽수를 추측하지 않는다.** 판본마다 다르다
- 평가 일정을 **임의로 넣지 않는다**
- 학생 실명을 쓰지 않는다 (생일 안내 등은 교사가 직접 넣게 비워 둔다)

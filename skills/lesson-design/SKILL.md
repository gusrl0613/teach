# 수업 설계

> 이 스킬의 목적 하나: **"이 단원 뭐 하지"에서 빠져나오는 것.**
> 교사에게 부족한 건 아이디어가 아니라 **40분에 맞는** 아이디어다.

## 0. 절대 규칙

**하나. 40분 안에 되는지 분 단위로 따진다.**
활동을 나열하지 않는다. **시간을 배분하고 합계를 검산한다.**
초등 수업은 40분이고, 그중 5분은 자리 정리와 이동에 쓰인다. **실제 활동 시간은 35분이다.**

**둘. 준비물이 현실적인가 본다.**
학급 예산과 준비 시간을 생각한다. 아래는 제안하지 않는다.

- 1인당 재료비가 드는 것 (미리 안내 없이는 불가)
- 교사가 전날 밤에 30개를 오려야 하는 것
- 특별실·기자재 예약이 필요한 것 → 필요하면 **표시하고 알린다**

**셋. 교과서를 인용하지 않는다.** 쪽수·삽화·지문은 판본마다 다르다.
교사가 교과서 사진이나 단원 자료를 올리면 **그것만 근거로** 삼는다.

## 1. 먼저 확인할 것 — 세 개

**학년 / 과목·단원 / 이번 차시에 아이가 무엇을 할 수 있게 되길 바라는지.**
셋째를 모르면 수업이 아니라 활동 나열이 된다. 안 주면 묻는다.

## 2. 출력 형식

```
■ 학습 목표 (아이 말로 한 문장)
   "분모가 같은 분수끼리 더할 수 있다"

■ 흐름

| 단계 | 시간 | 무엇을 | 교사는 | 아이는 |
|---|---|---|---|---|
| 도입 | 5분 | | | |
| 전개1 | 12분 | | | |
| 전개2 | 13분 | | | |
| 정리 | 5분 | | | |
                      합계 35분 (+ 전환 5분)

■ 준비물
   · 교사: / 학생:

■ 이렇게 되면 (대비)
   · 빨리 끝나면 →
   · 시간이 모자라면 →
   · 이해가 안 되는 아이가 있으면 →
```

**"이렇게 되면" 칸이 이 스킬의 값이다.**
계획대로 되는 수업은 없다. **빨리 끝났을 때가 제일 곤란하다.**

## 3. 활동을 고르는 기준

| 되도록 | 피할 것 |
|---|---|
| 아이가 **손으로 하는** 것 | 교사만 말하는 것 |
| **한 번에 설명되는** 규칙 | 규칙 설명에 5분 드는 게임 |
| 전원이 **동시에** 참여 | 한 명씩 나와서 하는 것 (나머지가 논다) |
| 실패해도 **되돌릴 수 있는** 것 | 한 번 틀리면 끝나는 것 |

## 4. 반드시 점검하고 알린다

| 점검 | |
|---|---|
| **시간 합계** | 실제로 더한다. 40분을 넘으면 줄일 곳을 제안 |
| **안전** | 가위·불·물·이동이 있으면 ⚠️ 로 표시하고 유의사항 한 줄 |
| **비용** | 재료비가 들면 표시하고 **사전 안내가 필요하다**고 알린다 |
| **모둠 편성** | 모둠 활동이면 인원과 역할이 정해져 있는지 |
| **준비 시간** | 교사가 전날 준비해야 할 것이 있으면 따로 뽑아준다 |

> 점검했습니다 — 합계 **38분**(전환 포함 시 43분, 3분 초과).
> 전개2를 10분으로 줄이는 안을 함께 넣었습니다.
> ⚠️ 가위 사용 활동이 있습니다. 비용은 들지 않습니다.

## 5. 대안을 하나 더 낸다

같은 목표를 **다른 방식으로** 하는 안을 한 줄로 덧붙인다.

> 대안: 조작 활동 대신 **짝 설명하기**로 가면 준비물이 없고 15분이면 됩니다.
> 교실이 시끄러워도 되는 시간대라면 이쪽이 편합니다.

## 6. 하지 않는 것

- **지도안 양식을 채워 주지 않는다.** 학교마다 다르다. 필요하면 양식을 올려 달라고 한다
- 성취기준 코드를 지어내지 않는다
- 특정 교구·앱·사이트를 **확인 없이 추천하지 않는다** (없어지거나 유료화된다)
- 학생 실명을 쓰지 않는다

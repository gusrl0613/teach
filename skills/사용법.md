# 스킬 사용법 — 이렇게 치면 이렇게 나옵니다

> 스킬은 **부르는 게 아니라 그냥 말하면 됩니다.**
> 설치해 두면 클로드가 알아서 꺼내 씁니다.

---

## 1. 설치 (한 번만, 2분)

### 준비

**설정 → 기능(Features) → "코드 실행 및 파일 생성" 켜기**

이게 꺼져 있으면 스킬이 아예 안 뜹니다. **가장 많이 빠뜨리는 단계입니다.**

### 올리기

1. 왼쪽 아래 본인 이름 → **Customize(내 설정) → Skills**
2. **`+` → 스킬 만들기 → 스킬 업로드**
3. `home-letter.zip` 선택
4. 나머지도 같은 방식으로. **한 번에 하나씩** 올립니다

> ⚠️ **Pro 이상에서만 올라갑니다.** 무료 계정이면 6번(프로젝트로 대신하기)으로 가세요.

---

## 2. 부르는 법 — 세 가지

### ① 그냥 말한다 (기본)

```
다음 주 현장체험학습 가정통신문 써줘.
10월 15일 과학관, 준비물은 도시락이랑 물, 회신 받아야 해.
```

`가정통신문` 이라는 말에서 클로드가 알아서 `home-letter` 를 꺼냅니다.
**스킬 이름을 몰라도 됩니다.**

### ② 지목한다 (확실히 하고 싶을 때)

```
가정통신문 스킬 써서 현장체험학습 안내문 만들어줘
```

### ③ 여러 개를 이어서 쓴다

```
이 관찰기록으로 상담 카드 만들어주고,
그중 12번은 학부모께 따로 문자 보낼 거라 그 초안도 같이 써줘
```

`counsel-prep` 과 `parent-message` 가 이어서 돕니다. **하나씩 나눠 물을 필요 없습니다.**

## 3. 실제 예시 — 그대로 따라 해보세요

### 예시 A. 가정통신문

**이렇게 칩니다**

```
10월 15일 과학관 현장체험학습 가정통신문 써줘.
5학년 3반. 8시 30분 출발, 3시 30분 도착.
도시락이랑 물, 편한 옷차림. 회신 필요해.
```

**이렇게 나옵니다**

- A4 한 장짜리 통신문 (제목·인사·본문·표·회신란·발신 명의)
- 준비물과 일정은 **표로**
- 절취선 있는 회신서
- 그리고 이런 점검 결과:

> 확인했습니다 — **10월 15일은 목요일**입니다.
> 채우실 칸 2개: `[ 학교명 ]`, `[ 회신 마감일 ]`. 비용은 주지 않으셔서 비워 뒀습니다.
> 워드 파일로 만들어 드릴까요?

**"응 워드로 줘"** 하면 `.docx` 파일이 나옵니다. 내려받아서 학교 양식에 붙이면 끝.

---

### 예시 B. 생기부 문구 (여러 명 한꺼번에)

**이렇게 칩니다** — 관찰기록을 그대로 붙여넣습니다

```
아래 관찰기록으로 행동특성 및 종합의견 써줘. 500자 이내.

3번
- 09-02 수학 전개도를 혼자 완성하고 모둠원에게 설명함
- 09-11 체육 진 뒤에 먼저 악수를 청함
- 09-18 준비물 없는 짝에게 자기 것을 나눠 씀
...

19번
- 09-08 사회 자료를 세 군데서 찾아 비교함
- 09-15 국어 문단 구분이 좋아짐
```

**이렇게 나옵니다**

| 번호 | 문구 | 글자수 | 근거 | 상태 |
|---|---|---|---|---|
| 3 | (문구) | 480 | 6건 | 충분 |
| 19 | — | — | 2건 | **근거 부족** |

> **19번은 문구를 만들지 않았습니다.** 기록 2건으로는 500자가 안 나옵니다.
> 지어내면 그게 그대로 기록에 남습니다.
> 지금 근거로 **2~3문장짜리 짧은 문구**는 만들 수 있습니다. 그렇게 할까요?

**이게 이 스킬의 핵심입니다.** 억지로 채우지 않습니다.

> 💡 실명으로 넣으면 클로드가 먼저 멈추고 번호로 바꿔 달라고 합니다. 그때 바꾸셔도 됩니다.

---

### 예시 C. 학부모 답장

**이렇게 칩니다** — 받은 문자를 그대로 붙여넣습니다

```
학부모님이 이렇게 보내셨어. 답장 초안 써줘.

"선생님 안녕하세요. 오늘 우리 아이가 울면서 왔는데
체육시간에 누가 밀었다고 하네요. 어떻게 된 건지 알고 싶습니다."

나는 그 상황을 직접 못 봤어. 내일 아이들한테 물어볼 예정이야.
```

**이렇게 나옵니다**

> 이 메시지는 **② 조심** 으로 보고 썼습니다.

초안 + 그리고 이런 점검표:

- [ ] `[확인 필요]` 표시가 남아 있지 않은가 — **남아 있으면 보내지 않습니다**
- [ ] "절대·다시는·반드시" 가 없는가
- [ ] 지금 보낼 시간인가 — **밤 9시 이후면 아침에**

> 더 짧게 가시려면: "어머님, 걱정 많으셨겠습니다. 오늘 상황 확인해서 내일 오전에 전화드리겠습니다."

---

### 예시 D. 자리배치

**이렇게 칩니다** — 명렬표 파일을 올리거나 조건만 말합니다

```
24명 자리배치 짜줘. 6줄 4열.
3번은 시력이 나빠서 앞자리, 19번은 휠체어라 통로 옆.
7번이랑 12번은 떨어뜨려 줘. 남녀 골고루.
```

**이렇게 나옵니다**

칠판 위치가 표시된 좌석표 + 그리고:

> ✅ 지킨 조건: 3번 앞자리 · 19번 통로 옆 · 7-12번 분리(3칸) · 남녀 2:2
> ⚠️ 못 지킨 조건: 5모둠이 4열에 3명 몰렸습니다 (배려 조건 우선한 결과)

**조건이 충돌하면 조용히 넘어가지 않고 알려줍니다.** 그게 이 스킬을 만든 이유입니다.

---

## 4. 파일로 받는 법

스킬들이 작업 끝에 **"파일로 만들어 드릴까요?"** 라고 묻습니다.

| 답하면 | 나오는 것 |
|---|---|
| "응 워드로" | `.docx` — 통신문·계획서·상담카드 |
| "엑셀로 줘" | `.xlsx` — 생기부 문구표·자리표·평가문항 |
| "PDF로" | `.pdf` — 인쇄용 |

오른쪽에 창이 열리고 **내려받기** 버튼이 생깁니다.
안 열리면 → **설정 → 기능 → "코드 실행 및 파일 생성"** 이 꺼진 겁니다.

---

## 5. 잘 쓰는 요령 다섯 가지

**① 자료를 주면 결과가 확 달라집니다.**
학교 양식, 작년 통신문, 기재요령 문서, 명렬표 — **파일로 올리면 그걸 기준으로** 씁니다.

**② 한 번에 끝내려 하지 마세요.**
"더 짧게", "더 정중하게", "3번은 다시" — **대화입니다.**

**③ 프로젝트와 같이 쓰면 제일 좋습니다.**
`우리 반` 프로젝트를 만들고 설명란에 이렇게 적어두세요.

```
나는 초등학교 5학년 3반 담임이다. 학생 24명.
학생은 항상 번호로만 지칭한다.
```

그 안에서 대화하면 **매번 학년·반을 안 말해도 됩니다.**

**④ 실명은 번호로.** 스킬들이 막아주긴 하지만, 애초에 안 넣는 게 빠릅니다.

**⑤ 나온 결과는 반드시 읽으세요.** 전부 초안입니다.

---

## 6. 무료 계정이면 — 프로젝트로 대신하기

커스텀 스킬 업로드는 유료(Pro 이상)입니다. 무료라면 이렇게 하세요.

1. 왼쪽 **프로젝트 → 새 프로젝트** → 이름 `가정통신문`
2. `SKILL.md` 를 메모장으로 열어 **맨 위 `---` 사이(name·description)만 빼고** 전부 복사
3. 프로젝트 **설명란(지침)** 에 붙여넣기
4. 앞으로 그 프로젝트 안에서 대화

**차이는 하나뿐입니다.** 스킬은 알아서 불려오고, 프로젝트는 **그 방에 들어가서** 말해야 합니다.
무료는 프로젝트 5개까지니, 자주 쓰실 것 다섯 개만 고르세요.

> 추천 다섯 개: `home-letter` · `record-phrase` · `parent-message` · `weekly-plan` · `counsel-prep`

## 7. 안 될 때

| 증상 | 이렇게 |
|---|---|
| **스킬이 안 불려온다** | 설정 → 기능 → "코드 실행 및 파일 생성" 확인. 그래도 안 되면 스킬 이름을 직접 대세요 |
| **업로드가 안 된다** | 무료 계정이면 안 됩니다. zip 안에 **폴더째** 들어 있는지도 확인 (`home-letter/SKILL.md`) |
| **파일이 안 나온다** | 같은 스위치입니다. 켜고 **대화를 새로 시작**하세요 |
| **엉뚱한 스킬이 불려온다** | 지목하세요. "생기부 스킬로 해줘" |
| **결과가 마음에 안 든다** | 다시 시키세요. "더 짧게", "표로", "3번만 다시" |
| **한도에 걸렸다** | 무료는 유료의 50%입니다. 몇 시간 뒤에 열립니다 |

---

## 8. 고쳐 쓰세요

`SKILL.md` 는 그냥 메모장으로 열리는 파일입니다.

- 학교 양식이 있으면 `home-letter/SKILL.md` 의 "기본 형식"을 바꾸세요
- 우리 학교 기재요령이 있으면 `record-phrase` 대화에 **첨부**하세요. 그 문서를 우선합니다
- 고친 뒤 **폴더를 우클릭 → 압축** 해서 다시 올리면 됩니다

**막히면 연락 주세요.** 혼자 하다 막히면 그냥 안 하게 됩니다.

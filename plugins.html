플러그인 — 여럿을
한 묶음으로

스킬 하나를 나눠주려면 zip 하나를 보내면 됩니다. 열 개를 스무 명에게 나눠주려면 이야기가 달라집니다.

한 문장으로

플러그인은 스킬 여러 개를 한 봉투에 담아 배포하는 것입니다.

스킬·에이전트·커넥터·자동실행 규칙을 하나로 묶어, 받는 사람이 명령 한 줄로 통째로 설치하게 만듭니다. 버전도 붙습니다. 내용을 고치면 받은 사람들에게 자동으로 갱신됩니다.

스킬플러그인
담기는 것절차 하나스킬 여러 개 + 커넥터 + 규칙
나눠주는 법zip을 각자 업로드명령 한 줄
고쳤을 때다시 나눠줘야 함자동 갱신
어디서claude.ai + 클로드 코드클로드 코드

먼저 솔직히 말씀드리면

플러그인은 claude.ai 채팅에는 없습니다

  • 플러그인은 클로드 코드의 기능입니다. 채팅창에서 쓰는 것이 아닙니다
  • 클로드 코드는 유료(Pro 이상)이고, 설치와 약간의 적응이 필요합니다
  • 공식 마켓플레이스의 플러그인은 대부분 개발자용입니다 — 언어 서버, 깃허브 연동, 코드 리뷰 같은 것들

그러니 개인 교사가 오늘 당장 필요한 건 아닙니다. 스킬 열 개로 충분합니다.

그런데 딱 한 경우 플러그인이 정확한 답이 됩니다.

같은 스킬 묶음을 여러 선생님에게 나눠줄 때.

학년 열 분, 학교 스무 분에게 스킬 열 개를 zip으로 보내면 200번의 업로드가 필요합니다. 하나를 고치면 또 200번입니다. 플러그인이면 한 줄씩 열 번이고, 고치면 알아서 갱신됩니다.

어떻게 생겼나

폴더 하나입니다. 안에 설명서와 스킬들이 들어 있습니다.

teacher-pack/ ├── .claude-plugin/ │ └── plugin.json ← 이름·설명·버전 └── skills/ ├── home-letter/SKILL.md ├── record-phrase/SKILL.md ├── parent-message/SKILL.md └── ... 10개

plugin.json 은 이렇게 짧습니다.

{ "name": "teacher-pack", "description": "초등교사 업무용 스킬 10종", "version": "1.0.0", "author": { "name": "이현기" } }

스킬 폴더를 그대로 옮겨 담은 것뿐입니다. 새로 배울 문법이 없습니다. 이미 만드신 SKILL.md 가 그대로 들어갑니다.

교사용 플러그인 — 실제로 만들어 뒀습니다

연수에서 쓴 스킬 10종을 하나로 묶었습니다. 이 저장소 안에 있습니다.

teacher-pack
가정통신문 · 주간학습안내 · 수업설계 · 평가문항 · 글쓰기피드백 · 자리배치 · 공문 · 학부모답장 · 상담준비 · 생기부문구 — 열 개 전부
설치는 두 줄
마켓플레이스를 등록하고 플러그인을 설치합니다. 스킬 열 개가 한 번에 들어갑니다

설치

클로드 코드를 열고 그 안에서 칩니다.

/plugin marketplace add gusrl0613/teach
/plugin install teacher-pack@teach

설치되면 스킬은 /teacher-pack:home-letter 처럼 플러그인 이름이 앞에 붙습니다. 이름이 겹치는 걸 막기 위해서입니다. 물론 이름을 안 부르고 그냥 “가정통신문 써줘”라고 해도 알아서 불려옵니다.

이 방법은 저장소에 접근할 수 있어야 합니다. 비공개 저장소라도 gh auth login 등으로 깃 자격증명이 잡혀 있으면 그대로 설치됩니다. 없으시면 아래 zip 방법을 쓰세요.

zip 파일로 설치하기 — 깃 없이

저장소 권한도, 깃도 필요 없습니다. 파일 하나면 됩니다.

teacher-pack.zip 내려받기 약 24 KB · 스킬 10종

내려받은 뒤, 그 파일이 있는 폴더에서 클로드 코드를 이렇게 엽니다.

claude --plugin-dir teacher-pack.zip

그 세션에서 스킬 10종이 그대로 뜹니다. 압축을 풀지 마세요. zip 그대로 넘깁니다.

여러 선생님께 나눠줄 때

zip을 웹에 올려두면 주소만 알려드리면 됩니다. 받는 쪽은 이 한 줄이면 끝입니다.

claude --plugin-url https://여기에-배포주소/teacher-pack.zip

※ 여기에-배포주소 부분은 이 사이트가 올라간 실제 주소로 바꿔 쓰세요.

마켓플레이스 카탈로그에 archive 소스로 등록해두면 /plugin install 로도 설치됩니다. 이 방식은 클로드 코드 v2.1.224 이상이 필요하고, 아카이브는 256 MiB까지입니다. 무결성 확인용 sha256 값은 저장소의 teacher-pack.zip.sha256 에 있습니다.

직접 테스트하지 못했습니다

  • 이 zip은 공식 문서의 규격에 맞춰 만들고 구조를 검증했습니다 — .claude-plugin/plugin.json 이 최상단에 있고 스킬 10종이 들어 있습니다
  • 다만 클로드 코드를 실제로 띄워 설치까지 해보지는 못했습니다. 처음 쓰실 때 안 되면 알려주세요

공식 마켓플레이스에 뭐가 있나

클로드 코드를 처음 켜면 공식 마켓플레이스가 자동으로 등록됩니다. /plugin 으로 둘러볼 수 있습니다.

아무거나 설치하지 마세요

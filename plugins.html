플러그인 — 여럿을
한 묶음으로

스킬 하나는 zip 하나를 보내면 됩니다. 열 개를 스무 분에게 나눠주려면 이야기가 달라집니다.

한 문장으로

플러그인은 스킬·커넥터·에이전트를 한 봉투에 담아 배포하는 것입니다.

받는 사람은 클릭 몇 번으로 통째로 설치합니다. 버전도 붙어서, 내용을 고치면 받은 분들에게 알아서 갱신됩니다.

스킬플러그인
담기는 것절차 하나스킬 여러 개 + 커넥터 + 에이전트
나눠주는 법zip 을 각자 업로드마켓플레이스 한 번
고쳤을 때다시 나눠줘야 함자동 갱신

스킬

커넥터
드라이브·지메일 같은 연결이 미리 설정된 채로 들어옵니다
서브에이전트

그래서 플러그인 하나를 깔면 첫 대화부터 준비된 상태가 됩니다 — 스킬을 하나씩 올리고 커넥터를 하나씩 연결할 필요가 없습니다.

스킬 폴더를 그대로 옮겨 담은 것뿐입니다. 새로 배울 문법이 없습니다.

teacher-pack — 실제로 만들어 뒀습니다

연수에서 쓴 스킬 10종을 하나로 묶었습니다. 상황에 맞는 길로 가시면 됩니다.

① 혼자 쓰신다면 — claude.ai 에서

클로드 웹에서 Customize → Plugins → Personal plugins 옆 ＋ → Add marketplace → 아래 주소를 넣습니다.

gusrl0613/teach

추가되면 목록에 teacher-pack 이 보입니다. 설치하면 스킬 10종이 한 번에 들어옵니다. 공개 저장소라 따로 받으실 권한은 없습니다.

② 학교·학년에 나눠주신다면 — 조직 설정에서 zip

학교가 Team 이나 Enterprise 플랜을 쓴다면 이게 가장 깔끔합니다. 한 번 올리면 선생님들 계정에 알아서 나타납니다.

teacher-pack.zip 내려받기 약 24 KB

  1. 조직 설정(Organization settings) → 플러그인(Plugins)
  2. Add plugins → Upload a file 선택
  3. 내려받은 teacher-pack.zip 을 올리고 마켓플레이스 이름을 정합니다

조건 세 가지

  • Team · Enterprise 의 소유자(Owner) 만 올릴 수 있습니다. Pro 개인은 ①번으로
  • 조직에 코워크와 스킬이 켜져 있어야 합니다
  • zip 은 50 MB 까지, 마켓플레이스당 100개까지

③ 클로드 코드를 쓰신다면

/plugin marketplace add gusrl0613/teach
/plugin install teacher-pack@teach

깃 없이 파일로만 쓰실 수도 있습니다.

claude --plugin-dir teacher-pack.zip

주소로 바로 넣는 방법도 있습니다 — claude --plugin-url https://raw.githubusercontent.com/gusrl0613/teach/main/teacher-pack.zip
마켓플레이스에 archive 소스로 등록하려면 클로드 코드 v2.1.224 이상이 필요하고, 이쪽 아카이브 상한은 256 MiB 입니다. 무결성 확인용 sha256 은 teacher-pack.zip.sha256 에 있습니다.

  • 설치 화면에 무엇이 들어오는지 목록이 나옵니다. 읽고 설치하세요
